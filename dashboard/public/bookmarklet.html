🔖 Etteum Cookie Exporter

1-klik copy cookie/token untuk Gemini, DeepSeek, Qwen, Z.AI Web — langsung paste ke Dashboard

Etteum Export Cookie

← Drag link di atas ke bookmarks bar kamu

Langkah 1: Drag tombol hitam di atas ke Bookmarks Bar (Ctrl+Shift+B untuk show bar)
Langkah 2: Buka salah satu:
  • gemini.google.com → login → klik bookmarklet → auto copy __Secure-1PSID
  • chat.deepseek.com → login → klik bookmarklet → auto copy userToken
  • chat.qwen.ai → login → klik bookmarklet → auto copy Cookie
  • chat.z.ai → login → klik bookmarklet → auto copy token
Langkah 3: Buka http://localhost:1931 → Accounts → pilih Gemini Web / DeepSeek Web / Qwen Web / Z.AI Web → Single → Email: bebas (ex: my@gmail.com), Password: paste cookie (Ctrl+V) → Add Account
⚠️ Cookie itu sensitif — jangan share. Etteum simpen ter-encrypt (XOR) di data/poolprox3.db pakai ENCRYPTION_KEY. Bookmarklet cuma jalan di browser kamu, nggak ngirim kemana-mana.

File bookmarklet: dashboard/public/etteum-cookie-exporter.js — bisa juga copy manual dari situ.
